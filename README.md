# Мини-синхронизатор заявок

Публичный JSON: https://orders-sync-klirikas.klirikas.chatgpt.site/api/clients

JavaScript без зависимостей. Каждый GET `/`, `/api/clients` или GET/POST `/api/sync` получает свежий массив с https://test.ooobs.ru/api/orders и возвращает только `clients` и `stats`.

## Правила

- Удаляются символы, кроме цифр. К 10 цифрам добавляется `7`; начальная `8` в 11-значном номере заменяется на `7`. Принимаются только `7` и 10 следующих цифр: `+7XXXXXXXXXX`.
- Для телефона выбирается вся запись с максимальным числовым `amount`, при равенстве — более поздняя `created_at`. При полном равенстве используется стабильный лексикографический выбор записи.
- `duplicates_merged = received - invalid_dropped - unique`. Клиенты отсортированы по телефону.
- Базы нет: каждый запрос строит результат заново. Неизменный вход даёт тот же ответ, включая порядок клиентов.
- Таймаут источника — 10 секунд. Ошибки сети и неверный формат источника дают HTTP 502.

## Локально

Node.js 22+, установка пакетов не нужна.

```sh
npm test
npm start
curl http://localhost:3000/api/clients
```

Переменные окружения: `PORT` (3000), `ORDERS_URL` (исходный API). Посетители не могут передавать произвольный URL источника.

## Деплой и секреты

Cloudflare Workers через Sites: `npm run build` создаёт `dist/server/index.js` и манифест. На Render/Railway сервис запускается командой `npm start` или через Docker.

Секреты для публичного источника не нужны. Токены деплоя передаются платформе вне исходников, будущие секреты — через переменные окружения хостинга; `.env` исключён из Git. Телефоны и email не пишутся в логи.
